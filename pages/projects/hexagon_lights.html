Hexagon Lights

Overview

I took a lot of inspiration from those garage hexagon lights, but I found them to be a bit boring and quite expensive. So I built my own customizable ones out of individually addressable LEDs, a raspberry pi, and aluminum channel. Once I mapped out the lights onto a 2D coordinate system, I was able to program various patterns and animations. When mounted on a wall, it only needs a few thumbtacks to hang onto the wall and hold it's shape. Mounting on the ceiling is a bit more difficult, but can be assembled piece by piece by yourself with a few drywall screws and sticky tack.

Description

This project measuring roughly 5.5ft x 5.5ft, features 570 individually addressable LED's. Over 32ft of aluminum channel, ~180 solder joints, and 84 3D printed parts.


The structure is built by 30 ~13" aluminum channels housing 19 LEDs each. The aluminum channel has a plastic LED diffuser that slots into the channel. At each end there is a 3D printed connector to form the structure and give a diffusion region to best try and hide the joint.


I mapped out the LED location on a 2D plane and a polar coordinate system. I then wrote various python scripts to display patterns and animations on the lights using a simple lookup table between the LED index and their coordinate.


Originally built on a raspberry pi zero W I quickly overwhelemed the processing capability and switched to a raspberry pi 3b+. Realistically, I should be using more embedded hardware like an arduino to control the lights and hook it up to a pi zero to get the best of both worlds. However, throwing a spare raspberry pi 3b+ at the problem was a simple plug and play solution and "There is nothing more permanent than a temporary solution".
