Spotify 2.0

Overview

Spotify 2.0 is a passion project of all the things I wish Spotify would do. Better playlist organization and management, better music discovery, better release rader, and a shuffler that is actually useful. I originally built the API handler but decided instead of running down the rabbit hole of each API bug, I would simply use spotipy which is a Python wrapper for the Spotify Web API. The project is under continual development and contains many features that are integral to the way I consume music.
